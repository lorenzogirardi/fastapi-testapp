# Assets

This directory holds supplementary assets for the agentic-workflows documentation.

Diagrams used in this documentation set are embedded directly as
[Mermaid](https://mermaid.js.org/) source inside the Markdown files, so no binary
image files are required. If you need to export a diagram as PNG/SVG for slides or
print, use a Mermaid renderer (e.g. `mmdc` or the Mermaid Live Editor) on the
fenced code blocks in `architecture.md` and `case-study-pr-8.md`.

- `architecture.md` — system context, component/data-flow, sequence, and trust-boundary diagrams
- `case-study-pr-8.md` — PR #8 review-flow diagram
